# XO | Tic-Tac-Toe and Dominoes

A polished browser game hub featuring local multiplayer Tic-Tac-Toe and Dominoes, with player profiles, scores, leaderboards, dashboard statistics, theme switching, and persistent browser data.

## Features

- Play local two-player Tic-Tac-Toe
- Play a local Dominoes match against the built-in opponent
- Track wins, draws, losses, and match history
- View dashboard statistics and leaderboards
- Configure player names and game settings
- Switch between light and dark themes
- Store game data in the browser using local storage
- Responsive layout for desktop and mobile screens

## Run Locally

No build tools or dependencies are required.

1. Download or clone this repository.
2. Open `index.html` in a modern web browser.

For the best development experience, serve the folder with a local static server, such as the VS Code Live Server extension.

## Project Structure

```text
.
├── index.html   # Application markup and game views
├── script.js    # Game logic, navigation, state, and local storage
├── style.css    # Layout, responsive styles, themes, and animations
└── README.md    # Project documentation
```

## Usage

Choose a game from the Games view, enter player names when prompted, and take turns using the on-screen controls. Use the Dashboard and Leaderboards views to review progress. Settings includes theme and stored-data controls.
